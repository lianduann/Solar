# 13. 商业应用：采购、开发与市场筛选

::: lead
**按读者类型的结论。** 供应商：组件价格便宜 10% 可节省 $3.76m，而模型测算的缺口为 $86.0m，因此应销售交付价值和文件证明，而不仅是价格。开发商：在没有税收抵免的情况下，所测试的任何路线都无法达到约 $44.6/MWh 的 2025 年德州电力可靠性委员会（ERCOT）公开报价，因此项目需要能够实际申领的税收抵免、更低的全口径成本，或愿意为电能之外的产品付费的买方。买方：应将报价与表 1-2 的枢纽对冲行以及表 13-2 的条款进行比较，而不是与一个标题平均值比较。储能：即使在参考节点进行完美的电能套利，2025 年也仅能达到成本区间的下限（第 12.4 节）。

## 13.1 设备供应商：在客户的系统内证明价值

具有商业实用性的采购评估分三个阶段：比较可比规格的到岸价格；评估兼容性、性能与可靠性；评估客户的并网与收入条件。设备降价只直接影响该评估的一部分，并不能保证做出建设决定。

因此，销售与策略材料应将产品属性与客户需求联系起来。现有证据既不衡量服务溢价，也不识别哪家供应商胜出；这类结论需要可比的产品、交付和客户证据。

就部件价格示例而言，美国组件投入成本降低 10% 可节省 $3.76m，参考情景净现值（NPV）仍为 −$82.20m。因此供应商应在组件报价之外，一并展示项目交付层面的节省、保修及系统方面的后果。适用的进口规则可能限制传导；与第 1.1 节定义的经补贴调整的美国组装基准的比较，仍取决于产品、日期和分母定义是否可比。[R-A, P01]

**表 13-1. 美国采购合同应问的问题。**

| 问题 | 签约前所需的证据 |
|---|---|
| 签约后贸易待遇发生变化时由谁承担？ | 法律变更、价格调整和终止条款 |
| 谁负责报关入境和关税？ | 登记进口商身份、交付条款以及最低进口价格（MIP）认证的准确性（第 3 条处罚） |
| 材料及其原产地能否追溯？ | 有文件记录的上游采购和海关合规证据 |
| 所有权和设备资格能否证实？ | 所有权/控制权记录及适用的税收资格文件（见第 10.8 节） |
| 设备延迟或性能不达标时怎么办？ | 交付里程碑、违约金、验收和保修救济 |
| 报价包含哪些内容？ | 通用规格、直流（DC）口径、运费、税费、保险和保修范围 |

*来源：第 5.7 节和第 10.8 节。问题是对分析字段的重述，不构成法律意见或指示性合同条款。*

纯设备供应商应证明所交付的产品和服务义务。设备/开发一体化企业还需要说明资产风险、所有权和融资；部件报价并不能确立这些项目经济性。

## 13.2 开发商：同时评估发电与付费规则

当结算时间、地点或合同规则变化时，相同的年发电量可能产生不同的收入。开发筛选应先确定场址、系统设计、结算点和商业安排，然后再赋予结果以资产层面的含义。

这些阈值可用于支持内部提问：报价变化是否大到足以改变情景；名义合同价格是否与实际成本一致；未付费电量条款如何影响资本回收。它们不构成可获得的融资方案，也不是已完成的项目评估。

在参考假设下，简化的节点级固定价格路线需要约 $66/MWh 的固定名义价格（枢纽对冲区间见第 10.3 节），而节点路线则要求资本支出（CAPEX）接近 $577/kWac，或价格曲线乘数接近 1.85。这些是可相互替代的盈亏平衡检验。2025 年中位数节点 NPV 为 −$81.3m，表明仅切换到中位数价格参考仍会留下相当大的模型缺口。[S08, E-A]

## 13.3 电力买方：比较产品与义务

电能、环境属性、按计划交付和持续供应是不同的采购目标。它们在数量、地点和短缺责任上各不相同。因此，两个以每 MWh 表示的价格可能指的是实质上不同的产品。

合同解读框架应在比较价格之前先识别这些责任。针对特定客户的采购建议需要关于实际产品和义务的证据，这不属于本报告的范围。第 10.3 节计算了枢纽对冲盈亏平衡，第 10.10 节给出公开报价参考，附录 B.2 列出合同风险分配，附录 C 列出交易尽职调查所需但未披露的条款。

**表 13-2. 比较标题价格之前的合同问题。**

| 问题 | 需核对的字段 |
|---|---|
| 买的是什么、付的是什么？ | 电能与环境属性；计量发电量与合同电量；付款中止 |
| 在哪里结算？ | 物理节点与金融枢纽；节点—枢纽价差（基差）的分配 |
| 期限结束后怎么办？ | 合同期限、剩余资产寿命和市场化尾期价格假设 |
| 谁承担不利事件？ | 负电价规则、短缺义务、不平衡、费用和担保品 |
| 报价是否可执行？ | 交易对手信用、担保、终止、法律变更和实际签署的条款 |

*来源：第 10.3 节、附录 B.2 和附录 C。问题是对分析字段的重述，不构成指示性市场条款。*

## 13.4 研究团队：检验市场论点中的每一环

更低的设备成本、不断增长的电力需求和更高的项目回报是相互独立的命题。逐环检验可以识别哪些额外证据可能改变结论，并避免重复收集一般性的背景材料。

本报告提供了制造业观察、区域运行背景和经济阈值。最有用的延伸方向涉及向到岸成本的传导、市场结果的代表性以及客户采购需求。

# 14. 展望与更新：具有可识别证据的条件性情景

## 14.1 现有证据所允许的范围

现有证据支持一个分析性的监测框架，但不支持独立的市场规模或电价预测。制造条件、负荷落实、电网发展和采购可能以不同速度演变，需要各自独立的指标。未经支持的增长率不会被写入未来年份的表格。

## 14.2 条件性市场发展

在供给侧，制造产量相对于销售量的持续削减可能使设备价格趋稳，并减少第 5 章所测试的组件节省。持续的价格竞争可能进一步压低出厂价格，而美国到岸层面的节省仍取决于产品准入、关税、物流和税收资格。这些都是条件性路径；本报告不对行业整合或限产赋予任何成功概率。

如果负荷落实快于电网扩建，地点差异、并网时间和可靠交付将成为进一步分析的重要问题。如果需求与电网发展同步推进，采购、竞争性供应和合同传导将成为核心。如果已公布的需求落实较慢，客户管线和设备需求预期需要重新评估。

这些是有待量化的逻辑情景。它们没有被赋予概率，也不能替代预测模型。

就光伏收入而言，第一条路径的影响是不明确的：稀缺可能支撑市场价格，但并网延迟和交付限制会损害收入的实现。负荷与电网的协调扩张可以改善市场准入，但竞争性供应可能吸收需求增量。在供给及其他条件不变的情况下，负荷落实放缓会削弱需求侧论点。这些路径在本报告中均没有量化的净价格效应。

## 14.4 对扩展投资证据的解读

三项区分决定了实证结果的使用方式。第一，历史上为正的模型结果以该价格模式为条件，并不是预期回报。第二，在两个历史价格年下普遍为负的结果，并不能证明每个光伏项目都不经济。第三，持续存在的节点价格差异并不能识别其成因。任何更强的主张都需要超出当前情景与关联框架的额外证据。

最有用的投资问题是：所提议的商业结构能否在完整且经证实的成本下支撑所需的收入。本研究提供了条件性阈值，并识别了对集中价格模式的暴露。未来价格、签约权利、税收资格、融资条款和收款概率仍未解决。

对于评估进入该市场的读者而言，直接的含义是：要像确认设备价格一样审慎地确认收入产品：仅电能销售、固定价格合同、曲线保证、稀缺参与和可靠供电分配的是不同的风险。合同可以转移暴露，而不是消除其成本。本报告不对这些路线做任何无依据的排序。

> **本章限制。** (1) 展望使用的是定性的条件性路径，未赋予概率。(2) 更快的负荷增长可能支撑价格，却会加剧准入和交付风险；对项目的净效应取决于地点、竞争性供应和合同条款。(3) 所需的额外证据列于附录 C。
